# tiny-dev-lab

พื้นที่ทดลองทำอะไรน่ารักๆ ให้แฟนด้วยโค้ด 💗

โปรเจกต์นี้เป็นเว็บเกมเลี้ยงแฮมสเตอร์จิ๋วชื่อ **Hamtaro House** ตั้งใจทำให้เป็นของขวัญดิจิทัลเล็กๆ ที่เปิดเล่นได้ง่าย และเติมความน่ารักลงไปในวันธรรมดา

## ในเว็บมีอะไรบ้าง

- ดูแลแฮมสเตอร์ชื่อ "โมจิ"
- ให้อาหาร เติมน้ำ เล่นด้วยกัน และทำความสะอาดห้อง
- ดูค่าความหิว ความกระหาย ความสนุก และความสะอาด
- เก็บเหรียญและดูแลโมจิให้มีความสุข
- รองรับการเปิดดูบนมือถือ

## วิธีเปิดเล่น

เปิดไฟล์ [hamtaro-house/index.html](hamtaro-house/index.html) ด้วยเว็บเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

โฟลเดอร์ `hamtaro-house` แยก HTML, CSS และ JavaScript เป็นสัดส่วน เพื่อให้แก้ไขข้อความ ชื่อแฮมสเตอร์ หรือเพิ่มไอเดียน่ารักๆ ให้แฟนได้สะดวก

## โครงสร้างโปรเจกต์

```text
hamtaro-house/
├── index.html   # โครงหน้าเว็บ
├── style.css    # สี เลย์เอาต์ และแอนิเมชัน
└── script.js    # ระบบดูแลโมจิและสถานะเกม
```
